# Безопасность и производительность

## Входные данные scanner

Scanner:

- рекурсивно обходит каталог;
- пропускает `node_modules`, скрытые каталоги и common output dirs;
- игнорирует симлинки;
- проверяет `isInsideRoot`;
- читает только TypeScript-файлы.

## Защита от traversal

`relativeModuleSpecifier` и `jsString` экранируют путь и сериализуют его как JSON-строку. Это защищает generated dynamic import от некорректных строк.

## Рекомендации по безопасности

- Держите `root` на доверенный корень проекта.
- Не сканируйте каталоги с generated code как source root.
- Не отключайте ограничения scanner без понимания последствий.
- Проверяйте dependency updates и audit.

## Scanner cache

Scanner кэширует результат по root URL. Сигнатура включает путь, mtime, размер и hash содержимого. Это делает инвалидацию надёжной, но стоит избегать вызова scanner в горячем цикле без нужды.

## Transform

Transform использует AST, поэтому работает быстро и не использует runtime reflection. MagicString генерирует source map.

## Бенчмарки

```bash
pnpm bench
```

## Практические советы

- Запускайте сборку после крупных изменений transform/runtime.
- Держите реализации рядом с интерфейсами.
- Избегайте сложных типов в конструкторах DI-классов, если не нужен ручной binding.
- Используйте scoped вместо transient, когда объекты можно переиспользовать в рамках операции.
